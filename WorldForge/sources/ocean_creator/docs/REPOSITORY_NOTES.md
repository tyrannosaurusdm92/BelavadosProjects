# Attached repository assistance notes

The attached archive contained four independent projects. Abyssal Atelier is a new implementation rather than a merged copy of those codebases.

- **DeepSee** informed the linked seafloor/3D inspection workflow and supplied the optional Pescadero slope-map reference. Its Apache-2.0 license is retained in `docs/licenses/DeepSee-APACHE-2.0.txt`.
- **Ocean Floor Mapping** informed the heightmap-import and bathymetric-relief workflow. No license file was present in the supplied archive, so its code and assets were not redistributed.
- **Ocean Navigator** informed the separation of time, depth, currents, and location telemetry. Its frontend package metadata states BSD-2-Clause, but no license text was present in the supplied archive, so its code and assets were not redistributed.
- **Visualizing Life in the Deep** informed the principle of mapping position, rotation, stroke, and glide signals into marine-animal animation. No license file was present in the supplied archive, so its code, Maya scenes, imagery, sounds, and models were not redistributed.

All procedural terrain, marine-life geometry, current animation, controls, presets, import/export behavior, interface code, and styling in Abyssal Atelier were created for this project.
