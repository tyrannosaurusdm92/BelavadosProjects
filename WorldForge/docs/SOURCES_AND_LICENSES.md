# Sources and Licenses

WorldForge was merged from user-provided project archives. Source/reference copies are retained under `sources/`, while license and notice files are retained under `docs/licenses/` and source-specific `docs` folders.

## Integrated project roles

- **WorldDepth 3D Map Studio:** core WebGL2 renderer, procedural geological model, cave mesh, local terrain, ZIP/DOCX importer.
- **Planetary 3D Weather Creator:** weather model and geological weather reference implementation. Retained under `sources/weather_creator/`.
- **Abyssal Atelier 3D Ocean Floor Creator:** ocean-floor and marine-life reference implementation. Retained under `sources/ocean_creator/`.
- **Fantasy Map Scanner Merged 3D:** terrain scanner, matcher, and Belavadös topography helper assets. Retained under `sources/map_scanner/` and `assets/topography/`.
- **WorldForge Settlement Map Generator:** only the LifeSimulator bridge concepts, maps, GeoJSON, reaction SVG library, terrain helper, and archived documentation were carried forward. The outdated settlement data and old endpoint were not made active.
- **settlements.zip:** authoritative current 28-province/279-settlement data copied to `data/settlements/`.

Third-party license texts from the attached projects remain with their respective source folders or under `docs/licenses/`. This integration report does not relicense third-party material.
